# External Integrations

## HuggingFace (models + diarization)

- **Purpose:** speaker diarization model (`pyannote/speaker-diarization-3.1`) + first-run model provisioning (`huggingface_hub.snapshot_download`)
- **Token config (two modes, see `config.py`):**
  - Dev checkout: `HF_TOKEN` env / `.env` (`.env.example` template)
  - Bundled service: Application Support `service_config` (ambient env/.env ignored — BR-19/BR-21); `current_hf_token()` re-reads live so a runtime change applies without restart
- **macOS UI:** token entered in first-run `SetupWizardView` and editable in `SettingsView` (#104); `SettingsTokenModel` → `ProvisioningController.submit(token:)` (`macos/Sources/MeetingTranscriberKit/Settings/SettingsTokenModel.swift`)
- **Graceful degradation:** empty token disables diarization rather than failing (BR-10)
- **Usage:** `backend/services/transcriber.py`

## WhisperX (local STT)

- **Source:** `git+https://github.com/m-bain/whisperX.git` (unpinned)
- **Model:** `WHISPER_MODEL` (default `large-v3`); device `WHISPER_DEVICE` auto → CUDA/CPU; `WHISPER_BATCH_SIZE` (16)
- **Usage:** `backend/services/transcriber.py`, `transcriber.py` (CLI)

## FFmpeg (vendored)

- **Purpose:** audio decode/preprocess for torchcodec + whisperx
- **Source:** pinned static arm64 build 7.1 from evermeet.cx via `scripts/vendor_ffmpeg.sh` → `vendor/bin`, embedded in the PyInstaller bundle; resolved at runtime by `app_paths.ffmpeg_path()`

## Sparkle (macOS auto-update)

- **Framework:** Sparkle 2.9.6 (SwiftPM, pinned exact)
- **Feed:** `SUFeedURL` = `https://github.com/nimblehq/audio-transcriber/releases/latest/download/appcast.xml` (`macos/Resources/Info.plist`)
- **Signing:** EdDSA `SUPublicEDKey` in Info.plist; private key injected in CI from `SPARKLE_ED_PRIVATE_KEY` secret; appcast generated by `macos/scripts/make_appcast.sh`, verified by `verify_update.sh`
- **Controller:** `macos/Sources/MeetingTranscriberApp/Update/UpdaterController.swift`

## GitHub (releases + CI/CD)

- **semantic-release** (`.releaserc.js`, `.github/workflows/release.yml`) on push to `main`; version bump from merged-PR labels (breaking→major, feature→minor, bug→patch); bare-semver tags, no `v` prefix
- **Release assets:** draft release created, then macOS `.app` zip + `appcast.xml` uploaded and draft flipped to published by `release-macos.yml` (runs in same run due to GITHUB_TOKEN recursion guard)
- **Service artifact fetch:** `macos/scripts/fetch_service.sh` downloads + verifies the pinned service against `macos/service-manifest.json` (via `gh`, GITHUB_TOKEN)
- **Auto-labeling:** `.github/workflows/auto-label.yml`; label setup `scripts/setup-release-labels.sh`
- **Secrets used:** `GITHUB_TOKEN`, `SPARKLE_ED_PUBLIC_KEY`, `SPARKLE_ED_PRIVATE_KEY`

## Native App ↔ Service (localhost IPC)

- App spawns the bundled Python service as a child process; service binds an ephemeral localhost port and announces it via stdout JSON handshake + `service.json` (`service_main.py`)
- Launch nonce `MT_SERVICE_NONCE` rejects stale/foreign services after PID reuse
- Readiness via `GET /api/health`; all app data flows over the FastAPI HTTP API (`APIClient` in `MeetingTranscriberKit`)

## Conductor (dev orchestration)

- `.conductor/settings.toml`: `make setup`; run modes `web` (FastAPI on `$CONDUCTOR_PORT`, default) and `app` (build+open macOS app, local-only)

## File System Storage

- All persistence, no DB. Dev: `DATA_DIR` (default `./data`); bundled: Application Support.
- Structure: `data/meetings/{uuid}/` → `metadata.json`, `transcript.json`, audio file. Analysis prompt templates in `templates/`.

## Not Integrated

- No database, message queue, cloud storage, or auth provider.
